# Corpus Manifest: Platform Hate Speech & Hateful Conduct Moderation Policies

## 1. What this corpus is

**52 official, first-party documents** — safety policies, community guidelines, enforcement
frameworks, and transparency materials — from five major social platforms.

| Platform | Documents |
| :--- | ---: |
| Meta (Facebook, Instagram, Threads) | 9 |
| YouTube (Google) | 20 |
| TikTok | 8 |
| X (formerly Twitter) | 6 |
| Reddit | 9 |
| **Total** | **52** |

* **Domain focus:** hate speech, harassment, violent extremism, dangerous organizations, and
  platform enforcement mechanics (strikes, appeals, quarantines, transparency reporting).
* **First-party only:** every document comes from the platform's own domain — help centre,
  transparency centre, newsroom, or policy site. No secondary commentary or press coverage.
* **Verified:** every URL below was confirmed to return the real policy text, by reading the
  extracted text rather than only checking the HTTP status or character count.

## 2. Question Scope

The corpus supports four question categories:

* **Factual & policy definitions:** prohibited characteristics, slurs, dehumanizing language
  rules, protected attributes.
* **Contextual exceptions:** educational/documentary/scientific/artistic (EDSA) context,
  counter-speech, reclaimed slurs.
* **Numerical & operational thresholds:** strike limits, quarantine/appeal criteria,
  enforcement report figures.
* **Cross-platform comparison:** how different platforms handle the same situation (e.g.
  account strikes, appeals, quarantine-equivalents).

## 4. Known limitations

- **Uneven platform coverage.** 20 YouTube documents against 6 for X. This tracks which
  domains permit automated fetching, not editorial judgment: YouTube's help centre answers
  plain GETs reliably, while Meta and X block non-browser clients and are only reachable
  through archived snapshots.
- **No JavaScript execution.** `src/fetch_corpus.py` performs a plain HTTP GET. Several
  platforms render policy text client-side, so a URL that looks fine in a browser can fetch
  as an empty app shell. Every URL above was verified against this by reading its extracted
  text; a page re-rendered as client-side-only after this manifest was written would need
  re-verifying the same way.
- **Wayback aliases can drift.** The generic `/web/2025/<url>` form resolves to whichever
  capture the Wayback Machine currently considers nearest, which can change between runs.
  `DOC-01` is pinned to an exact snapshot timestamp for this reason. If a wayback-sourced
  document ever comes back unexpectedly thin, pin its timestamp the same way.
